# Team tasks

Small, self-contained pieces of Confox for each team member. Each brief is written so that you, or a coding agent you run, can build it without the rest of the conversation.

| Task | Owner | Area | Brief |
|---|---|---|---|
| SessionCard component | [@FIZ55](https://github.com/FIZ55) | Frontend | [session-card.md](session-card.md) |
| `next_food()` helper | [@yuzimeng2000-coder](https://github.com/yuzimeng2000-coder) | Backend | [next-food.md](next-food.md) |

## How every task works

1. Clone the repo and create the branch named in the brief.
2. Read the brief, [`.gitar/review/confox.md`](../../.gitar/review/confox.md) (our review rules) and [`docs/idea.md`](../idea.md).
3. Build only what the brief asks for, in the files it names. Do not edit other files.
4. Run the checks in the brief. They must pass.
5. Commit under your own GitHub account and open a pull request against `main`. Gitar reviews it and CI runs; the team reviews and merges.
6. If you used an AI coding assistant, say so in the pull request description (hackathon rule 5), and make sure you can explain every line (rule 6).
